# Performance testing

The numbers in the README come from the test procedure here. Anyone can reproduce them on their own machine with the same scripts.

## Environment

| Item | Value |
|---|---|
| Date | 2026-11-03 |
| Source | `0e92b51`, `cargo build --release --locked` |
| Machine | Apple M5 Pro / 48 GiB, macOS 26.5 |
| Window | 1280 × 800 pt, 2× scale, Craft theme |
| Document | 1,001,307 characters, 549 chapters generated by the [sample generator](../tools/perf/gen_library.py), containing paragraphs, lists, tables, and code |

## Method

[harness](../tools/harness/README.md) replays [readme-performance.txt](../tools/harness/examples/readme-performance.txt): open the million-character document, insert 100 `x`s in a row at the end of the first paragraph, then backspace 100 times, then scroll down 100 times.

`bench` calls `window.draw` synchronously after sending each operation, recording the processing time of that frame (logged as `frame`). P50 is the median, P95 is the 95th percentile. This measures in-app frame processing time, excluding screen presentation latency — it is not the same as end-to-end keyboard-to-screen latency. This is a single-machine measurement; it does not represent every device, and is not a comparison against other apps.

## Results

| Operation | Frame processing P50 | Frame processing P95 | Max |
|---|---:|---:|---:|
| Continuous typing | 5.06 ms | 5.78 ms | 6.94 ms |
| Continuous backspace | 4.99 ms | 5.55 ms | 5.69 ms |
| Continuous scrolling | 2.08 ms | 4.14 ms | 9.23 ms |

Raw output (ms):

```text
bench "type x" x100: step [p50 0.03 p95 0.05 max 5.29] frame [p50 5.06 p95 5.78 max 6.94] editor render [p50 3.77 p95 4.31 max 4.99] ms
bench "key backspace" x100: step [p50 0.02 p95 0.05 max 3.91] frame [p50 4.99 p95 5.55 max 5.69] editor render [p50 3.64 p95 4.12 max 4.24] ms
bench "wheel 900 500 40" x100: step [p50 0.01 p95 0.02 max 0.02] frame [p50 2.08 p95 4.14 max 9.23] editor render [p50 0.02 p95 0.03 max 1.83] ms
```

## Reproducing

The test only uses a temporary library, never touching `~/Documents/Quiet.md`.

```sh
cargo build --release --locked --features devtools
python3 tools/perf/gen_library.py /tmp/quiet-perf/library
printf '{"english":true,"theme":"craft"}\n' > /tmp/quiet-perf/library/preferences.json
python3 tools/harness/run.py tools/harness/examples/readme-performance.txt /tmp/quiet-perf/library /tmp/quiet-perf/run
grep -a bench /tmp/quiet-perf/run/log
```
