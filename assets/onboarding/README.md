# First-launch opener

`intro.png` is the pixel animation played full-window on first launch (`src/onboarding.rs`):

- The first row is a 16-color palette (RGB bytes), and every 225 rows after that is one frame, 400×225 pixels, 12 fps;
- Each frame stores "palette index × 17", XORed against the previous frame, so a static area takes up almost no space;
- On each frame change, the app scales that frame up 4x with nearest-neighbor into a texture handed to the GPU — pixels stay crisp when scaled up, and only one image is drawn per frame; it loops back and forth, and after 1 second the glowing word "ducko" fades in at the center along its letters, after which the onboarding page overlays directly on top of the still-playing clip.

The asset is a 5-second video generated by this project with Seedance 2.5 (LibTV, first-frame-to-video): the first frame is a version of the site's grassy-slope image `site/public/bg.png`, cropped to 16:9 with dithering removed, with only the branches and grass swaying gently in the clip. It's then run through `tools/onboarding/intro.py`, which generates ordered dithering using `bg.png`'s own 16-color palette, matching the site's pixel look:

```sh
python3 tools/onboarding/intro.py <video.mp4> assets/onboarding/intro.png --palette site/public/bg.png --fps 12 --w 400 --h 225
```
